# AgriShield

## Satellite-based Agricultural Drought Intelligence & Early Warning System

AgriShield is a satellite-based agricultural drought monitoring dashboard that combines Sentinel-2 satellite observations with weather information to identify vegetation, moisture, temperature and rainfall stress.

## Features

- Sentinel-2 NDVI monitoring
- Sentinel-2 NDMI monitoring
- Weather monitoring
- Agricultural drought stress score
- Interactive agricultural map
- NDVI vegetation trend
- Agricultural advisory
- Priority agricultural areas
- Real-time location selection

## Technologies

- Python
- Streamlit
- Google Earth Engine
- Sentinel-2
- Open-Meteo
- Folium
- Pandas
